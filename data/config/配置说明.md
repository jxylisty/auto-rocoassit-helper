# 咕噜球 / 挂机引擎 配置速查

本文件汇总近期新增功能的全部配置项与所在位置，避免翻代码找开关。

## 一、`data/config/ball_watch.json` — 球槽监视（丢球助手）

| 键 | 默认 | 说明 |
|---|---|---|
| `mode` | `"log"` | `log` = 只记日志不干预丢球（先验证识别）; `stop` = 空球/贵重球自动停止丢球 |
| `present_threshold` | `0.6` | 模板匹配分数阈值，识别不稳可上调到 0.65 |
| `prefer` | `"official"` | 模板来源优先级：`official` = 官方高清图标；`ingame` = `data/vision/ball_templates/` 里的游戏内截图 |
| `active_balls` | 20 个 id | 实际存在的球白名单（不在名单的模板是噪音） |
| `protected_ids` | 空 | 贵重球 id 名单，留空自动用品质≥5 的球（国王球/棱镜系等） |
| `ocr_interval` | `12` | 数量 OCR 间隔（秒），独立线程跑不占丢球 |

球模板目录：`data/vision/ball_icons/`（官方，自动下载）与 `data/vision/ball_templates/`（游戏内截图，命名 `{id}_{球名}.png`）。

## 二、`settings.yaml` → `battle:` 段 — 挂机引擎

| 键 | 默认 | 说明 |
|---|---|---|
| `battle.catch_hp` | 5 | 捕获血线（%） |
| `battle.open_ball_key` | `"w"` | 开丢球界面键 |
| `battle.ball_slot_key` | `"1"` | 旧槽位键流程的球槽（识别不可用时回退） |
| `battle.safe_ball_ids` | `["100003","540801"]` | 战斗内识别的安全球名单（默认高级咕噜球），识别到贵重球自动滚轮切换 |
| `battle.strict_safe` | `false` | 切不到安全球时：`true` = 放弃丢球；`false` = 按非严格丢弃 |
| `battle.shiny_stop` | `true` | 检测到异色提示文本时自动停止引擎（让你手动捕捉）；`false` = 只计数不停机 |

## 三、挂机引擎异色检测（已内置）

进战斗 1.5 秒后对整帧做一次 OCR，命中“异色”关键词即计数（`🌈 异色`），每场去重，
计数显示在挂机引擎页「🌈 异色」卡片。无需配置，`battle.shiny_stop` 控制停不停。

## 四、背包盘点（手动按钮）

丢球助手页库存卡「📦 背包盘点」：需先在视觉调试台框好 `背包.json`（roi_1 = 网格(0,0)格、
roi_2 = (1,1)对角格、背包整体ocr = 网格总区域），自动推得 dx/dy 网格并逐格识别球种+数量，
与上次快照做减法显示“较上次消耗”。快照存 `data/config/bag_inventory.json`。

## 五、异色手动记录（丢球助手页）

「异色记录」卡片 +1/-1 按钮，存浏览器 localStorage（`lkw_shiny`），自动算“约 N 球/只”。

## 已知边界

- 美妙球 ↔ 奇趣球：官方图标同色系，40px 槽位上互认错（仅显示层，不影响自动逻辑）；
  右下角大图标通道或游戏内模板可解，当前默认接受。
