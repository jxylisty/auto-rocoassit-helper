# 卡密验证服务部署说明 · v2 加固版 (Cloudflare Workers, 免费档)

> **v2 变更**：响应签名升级为 Ed25519（私钥只在 Worker）；activate/verify 响应附带
> `seed`（核心数据解密种子）；客户端 `api_base` 已内置进 pyd，不再需要配置 auth.json。
> 未做 v2 变量的旧 Worker 仍可服务旧客户端（通道 HMAC 兼容），但建议尽快升级。

## 1. 注册 Cloudflare

打开 https://dash.cloudflare.com/sign-up 注册(免费, 不用绑卡)。

## 2. 创建 KV 存储

控制台左侧 → **Storage & Databases → KV** → **Create namespace** → 名字填 `AUTH_CODES` → 创建。

## 3. 创建 Worker 并粘贴代码

左侧 **Workers & Pages** → **Create application → Create Worker** → 名字随意(如 `lkw-auth`)→ Deploy。
部署后点 **Edit code**，全选删除默认代码，把本目录 `worker.js` 的**全部内容**粘贴进去。

## 4. 配置环境变量与 KV 绑定

回到 Worker 页 → **Settings** → **Variables and Secrets** → Add：

| 变量 | 说明 |
|---|---|
| `ADMIN_KEY` | 管理密钥(管理页要用, 别告诉别人) |
| `SIGN_SALT` | token 签名盐(随机字符串) |
| `DATA_SEED` | **v2 必填**：数据解密种子 = 本机 `build/_hardened/keys.json` 的 `data_seed` (64位hex) |
| `ED25519_PRIVATE_KEY` | **v2 必填**：Ed25519 私钥 = `keys.json` 的 `ed25519_private_pkcs8` (PKCS8 hex) |

生成随机串：`python -c "import secrets;print(secrets.token_hex(32))"`

**Bindings** → Add → KV namespace：变量名 `AUTH_CODES` → 选第 2 步的命名空间 → **Deploy**。

## 5. 自检

浏览器打开 `https://你的worker地址/healthz`，应返回：

```json
{"ok":true,"service":"lkw-auth","ed25519":true,"seed":true}
```

两项都是 true 才说明 v2 变量配置成功。

## 6. 生成卡密 & 发给朋友

浏览器打开 `https://你的worker地址/admin?key=***`：

- 选时长/数量 → 生成 → 复制卡密(格式 `LK-XXXX-XXXX-XXXX`)发给朋友
- 列表可看每张卡状态(未用/已绑定/已吊销)、到期时间；可随时吊销

朋友在客户端输入卡密即完成绑定(一码一机)。

## 7. 客户端构建流程 (对应关系)

```
tools/build_hardened.py      # 一键: 密钥管理 → Cython 编译 → 数据加密 → 冒烟 → 打包 → 检查
  ├─ build/_hardened/keys.json   # 本机密钥库 (不进 git!)
  │     ├─ data_seed               → 填 Worker 的 DATA_SEED
  │     ├─ ed25519_private_pkcs8   → 填 Worker 的 ED25519_PRIVATE_KEY
  │     └─ ed25519_public_raw      → 自动写进 auth_core.py 公钥锚点 (公开, 可入 git)
  └─ dist/洛克王国助手/           # 分发包 (数据只有 .bin 密文, 无明文核心数据)
```

## 常用操作

| 操作 | 方法 |
|---|---|
| 朋友换电脑 | 绑定超 72h 可客户端自助换机；不足 72h 用 `/deactivate` 带 admin_key 解绑 |
| 卡密泄露/退款 | 管理页「吊销」 |
| 延长时长 | 吊销旧的 → 生成新的发过去 |
| 轮换数据密钥 | 本机 `python tools/build_hardened.py --rotate` → 重新分发 → 同步 Worker 的 `DATA_SEED`/`ED25519_PRIVATE_KEY`（旧分发包数据将不可读，用于密钥疑似泄露时） |

## 安全说明 (v2)

- token = HMAC-SHA256(机器码|到期时间, SIGN_SALT)，拿到 token 无法伪造/延期
- **响应 Ed25519 签名**：私钥只在 Worker，客户端公钥锚定在 auth_core.pyd 内——假服务端/中间人无法伪造合法响应；api_base 已内置进 pyd，改 auth.json 无效
- **核心数据加密**：分发包内精灵/技能数据只有密文(.bin)，解密密钥由激活/校验响应的 seed 在内存派生，不落盘——破解者绕过授权提示也拿不到数据
- 卡密一码绑一机(hwid 含 MAC+主机名+MachineGuid)，换机需解绑(72h 冷却防共享)
- 断网宽限 7 天上限（首次激活 30 分钟）：激活一次永久断网不再可行
- 本地 auth.json 不再含 api_base/token 明文以外敏感项；seed 以本机绑定混淆缓存存储，整目录拷贝到别的机器无法还原
- 换 SIGN_SALT = 所有已发 token 立即作废(紧急止血)；轮换 DATA_SEED = 所有旧分发包数据作废
