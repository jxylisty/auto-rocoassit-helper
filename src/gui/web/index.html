MCP 自玩 AI 操作游戏

                    
让 AI 客户端读局势 + 自主按键操作 · 需额外配置

                

            


            

                
原理

                

                    AI 客户端(ZCode/Claude Desktop/Cline 等)通过 MCP 协议连接到本程序,
                    可以读取实时对局快照、规则、伤害推演, 然后用 pvp_act 工具
                    直接按键操作游戏(技能/聚能/换宠/愿力冲击)。
                

                

                    
MCP 工具一览（共 8 个）:

                    
📷 pvp_snapshot — 实时战况(双方精灵/血量/能量/伤害推演)

                    
📖 pvp_rules — PVP 规则知识包(克制表/伤害公式/先手规则)

                    
⚔️ pvp_analyze_matchup — 精算指定精灵对局推演

                    
🔍 pvp_search — 模糊搜索精灵/技能

                    
📜 pvp_rounds_list / pvp_round_log — 回合日志复盘

                    
🏆 pvp_history — 战报历史(手动录入)

                    
⚡ pvp_act — 按键操作(skill1~4 / energize / switch_1~6 / resonance)

                


                
接入步骤

                
    
                    
  1. 启动本程序(保持后台运行, 端口 17365)
    2. 
                    
  2. 在 AI 客户端(ZCode/Claude Desktop/Cline)的 MCP 配置中添加：
    3. 
                

                
{
  "mcpServers": {
    "lkw-pvp": {
      "command": "D:/anaconda/python.exe",
      "args": ["D:/洛克王国ai/lkwgai_pvp_assistant/tools/pvp_mcp_server.py"]
    }
  }
}

                

                    ③ 重启 AI 客户端 → 连接后向 AI 提问"帮我打一场 PVP"，AI 会
                    通过 MCP 读局势 → 决策 → 用 pvp_act 按键操作。
